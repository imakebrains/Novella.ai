# Novel Day One

Goal: leave the project in a state where tomorrow's session can start writing in
under two minutes.

## 1. The repo (insurance first)

- Project folder → `git init` → `.gitignore` containing `build/`
- First commit ("day one"). Every future session ends with a commit; no draft is
  ever lost again.

## 2. The state scaffold

- Run master-novel init if available: creates `story-state/` (scene functions,
  promise ledger, knowledge/relationship state, irony tracker, reader-experience map,
  reveal ledger, motif registry, causality ledger, open threads, voice anchor,
  session log).
- If another bible system exists (story-skills, an existing `bible/`), write
  `story-state/BIBLE.md` as a pointer to it. One canon owner, ever.
- Without the stack: create the ledgers as plain markdown tables by hand — the
  discipline matters more than the tooling.

## 3. The voice

- Adopt a register (e.g. conversational-authority) **or** seed `voice-anchor.md`
  from 2–3 passages of the writer's own strongest prose.
- Record the fingerprint: sentence rhythm, interiority depth, metaphor domains,
  lexical tics, and "what this narrator never does".

## 4. The premise

Brainstorm with whatever ideation skill is present (muse, fiction-studio) or directly:

- Premise in two sentences; the impossible choice it will force
- POV scheme and tense — decided now, drifted never
- Genre + target word count (sanity-check against genre norms)
- The 3–5 opening **promises**: what the reader will be reading FOR. Enter them in
  `promise-ledger.md` before a word of prose exists — a book opens by making promises.

## 5. Done-check

- [ ] git repo with first commit
- [ ] `story-state/` scaffolded, canon owner named
- [ ] voice anchor seeded
- [ ] premise, POV, genre, word-count target logged in the bible
- [ ] first promises planted
- [ ] `session-log.md` ends with: "Next: draft 1.1 — target feeling: ___"

Do not draft chapter one today unless the writer insists. Setup is a session;
momentum comes from arriving tomorrow with everything ready.
