# Craft sources — human-authored, verified

The distillation shelf: publicly available writing-craft sources by real
practitioners (novelists, editors, screenwriters), gathered by the skills
scouting rounds (see SKILLS.md at the repo root). Every entry names its
author because that's the point — this library prefers what working
writers actually published over AI content farms. Cite ideas from these;
never copy their text into skills.

Status legend: **queued** = next in line to be distilled into a skill or
template · **distilled** = a skill/template in this library now carries it
· **reference** = consult when relevant, not skill-shaped · **blocked** =
site unreachable from the research environment last check.
