# Standard Manuscript Format — submission checklist

Reference: William Shunn's manuscript format guide (https://www.shunn.net/format/).
The items below restate the conventions in our own words; consult the guide
itself for edge cases and worked examples.

Walk every item before the DOCX leaves the building.

## Page setup

- [ ] 12-point serif font throughout (Times New Roman is the safe default;
      Courier is the traditional alternative). One font, one size, everywhere.
- [ ] 1-inch margins on all four sides.
- [ ] Double-spaced body text. No extra blank lines between paragraphs.
- [ ] First line of every paragraph indented ~0.5" via paragraph style —
      never with tabs or spaces.
- [ ] Left-aligned (ragged right). No full justification.
- [ ] Black text on white. No colors, no decorative fonts anywhere.

## First page

- [ ] Contact block top-left: legal name, mailing address, phone, email
      (agent's details instead, if agented).
- [ ] Approximate word count top-right, rounded (e.g. "about 92,000 words").
- [ ] Title centered roughly a third to halfway down the page, byline
      ("by Author Name" or pen name) centered below it.
- [ ] Text begins below the byline on the same page; no separate cover page
      unless guidelines ask for one.

## Every subsequent page

- [ ] Running header top-right: Surname / TITLE (or keyword) / page number.
- [ ] No header on page one.
- [ ] Page numbers continuous across chapters.

## Body conventions

- [ ] New chapters start on a new page, chapter heading about a third of the
      way down.
- [ ] Scene breaks marked with a single centered `#` (blank lines vanish at
      page boundaries; the `#` doesn't).
- [ ] Italics rendered as italics. (Underlining-for-italics is the legacy
      Courier convention — use only if guidelines request it.)
- [ ] Em dashes and ellipses used consistently; straight or curly quotes,
      but one or the other throughout.
- [ ] "END" or "# # #" centered after the final line.

## Before sending

- [ ] File named per the recipient's guidelines (default:
      Surname_TITLE.docx).
- [ ] Their submission guidelines re-read start to finish — individual
      guidelines override every item above.
- [ ] Spell-check run in the DOCX itself (conversion can introduce artifacts).
- [ ] Opened and eyeballed on a second device or in print preview.
