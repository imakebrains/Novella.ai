# Novel Scene — Load, Contract, Draft, Update

## 1. Context load (only these slices — never the whole state)

- `scene-functions.md`: the previous 2–3 rows, plus this scene's planned function
- `relationship-state.md`: current standing + "what remains unsaid" for the
  characters in this scene
- `knowledge-state.md`: rows for the characters present (prevents impossible
  knowledge — the classic multi-POV bug)
- `promise-ledger.md`: promises due or available for reinforcement here
- `reader-experience.md`: this chapter's target feeling, and the previous two actuals
  (never three chapters on the same note)
- `voice-anchor.md`: full read
- `motif-registry.md`: motifs available for an echo

## 2. The scene contract (one line, before any prose)

> "This scene exists to ___. When it ends: ___ (state changes)."

If the blank after "exists to" can only be filled with "show" or "establish mood",
stop — wire the scene to a want, a promise, or a relationship delta first.

## 3. Draft

In the book's register (voice anchor / conversational-authority rules). Draft the
whole scene before evaluating; drafting and judging use different heads.

## 4. After-scene update (fixed order, ~2 minutes, deltas only)

1. `scene-functions.md` — the row: POV | Want | Conflict | Change | Revelation |
   Emotional shift | Exit condition. **If Change AND Revelation are both "—",
   flag the scene now — don't wait for an audit.**
2. `causality-ledger.md` — Event → Interpretation → Emotion → Decision →
   (Consequence lands in: backfill later)
3. `knowledge-state.md` + `irony-tracker.md` — who learned/mislearned/hid what;
   what the reader learned; gaps opened or closed
4. `relationship-state.md` — signed deltas per pair present, both interpretations,
   what's now unsaid
5. `promise-ledger.md` / `reveal-ledger.md` / `motif-registry.md` — anything planted,
   reinforced, complicated, paid, revealed, or echoed
6. `reader-experience.md` — update the chapter's row
7. Threads — `open-threads.md`, or the story-graph tool if installed

## Rules

- Append, never rewrite ledger history.
- Every entry cites `chapter.scene`.
- Do NOT line-edit while drafting — that's a finishing pass. Forward motion first.
